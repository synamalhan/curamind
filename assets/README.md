# Assets Directory

This directory contains static assets for the CuraMind application:

## Structure

- `icons/` - Application icons and UI icons
- `images/` - Stock photos and illustrations (linked from Pexels)
- `audio/` - Sound files for ambient sounds and notifications
- `fonts/` - Custom fonts if needed

## Usage

- All images should be optimized for web
- Use appropriate alt text for accessibility
- Icons should be SVG format when possible
- Audio files should be compressed for web delivery
